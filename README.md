# Игротека / GameCenter

Семейные игры в браузере: <https://ktibr0.github.io/>. Преимущественно два человека совместно играют на одном 10″ планшете. GitHub Pages остаётся площадкой публикации.

## Для нового чата

1. Прочитать [AGENTS.md](AGENTS.md).
2. Прочитать [передачу контекста](docs/HANDOFF.md) и [TODO](TODO.md).
3. Выбрать небольшой этап, составить план по файлам и критерии до реализации.
4. Проверки и публикация: [TESTING-AND-RELEASE.md](docs/TESTING-AND-RELEASE.md).

## Карта проекта

| Путь | Состояние |
|---|---|
| `index.html` | Главная со ссылками на игры; ArcoMage пока ведёт на внешний сайт |
| `cryptographer/` | Обновлена и опубликована; CSV, правила, UI и стили разделены |
| `sumplete/index.html` | Собственный генератор и UI в одном файле; следующий основной кандидат на доработку |
| `rsvp/index.html`, `rsvp/rsvp.swf` | Оболочка RSVP и Flash-игра |
| `rsvp/ruffle/` | Общий runtime для RSVP и Jelly Battle; не изменять в текущем плане |
| `arcomage-hd/`, `arcomage-hd/dist/` | Готовые сборки и ресурсы; исходный проект сборки здесь не обнаружен |
| `jellybattle/`, `jellybattle.zip` | Исключены из работ; отдельный проект переписывания |
| `tests/cryptographer/` | Независимые проверки выпущенного Криптографа |
| `_work/` | Сохраняемые локальные журналы, scripts и screenshots, не публикуются Git |

## Локальный запуск

Из этого каталога: `python -m http.server 8000 --bind 127.0.0.1`, затем <http://127.0.0.1:8000/>. Прямой `file://` не подходит для загрузки CSV и модулей. Это локальный сервер проверки; на Pages сервер приложений не нужен. Не считать наличие Node/Python обязательным для игроков.
