# Криптограмма

Небольшая браузерная игра на русском языке. Откройте `index.html` через статический HTTP сервер или GitHub Pages. Для `file://` загрузка CSV браузером обычно запрещена.

## Данные цитат

`quotes.csv` — UTF-8 CSV с заголовком `id,text,author,category`. Обязательно заключайте текстовые поля в кавычки; кавычку внутри поля записывайте дважды. Переносы строк, запятые и Unicode поддерживаются; переносы внутри фразы отображаются как пробелы. `id` должен оставаться неизменным при перемещении и правке строки. Для новой фразы используйте следующий свободный понятный ID, например `quote-0711`; не меняйте его при перестановке строки или правке текста. В исходной миграции ID вычислен как короткий SHA-256 от нормализованной фразы. Не меняйте формулировку и авторство без источника.

Для правки удобно открыть CSV в редакторе с поддержкой UTF-8 или таблице. Выберите импорт с разделителем запятая и сохраните именно как CSV UTF-8 (в русской локали Excel иногда предлагает точку с запятой; игра ожидает запятые). Проверьте первую строку и что кавычки удвоены. Игра удаляет повторы по нормализованному тексту (регистр, `е/ё`, пунктуация и пробелы не различаются), а одинаковые стабильные ID отклоняет.

## Публикация

При локальной проверке запустите любой статический HTTP сервер из каталога репозитория и откройте `/cryptographer/`. В Pages файлы `index.html`, `app.js`, `game.js`, `data.js`, `styles.css` и `quotes.csv` должны публиковаться вместе. CSV запрашивается с `cache: no-store`, поэтому браузер проверяет свежую версию при открытии приложения.

## Сохранение игры

Текущая фраза (включая текстовый снимок), шифр, выбранная ячейка, открытия, жизни, подсказки и остаток колоды хранятся в `localStorage` этого браузера и сайта. Обновление CSV не ломает сохранённую незавершённую партию. Новая партия начинается только после выбора сложности; до этого можно продолжить сохранённую игру. Очистка данных сайта или приватное окно удаляют сохранение. При недоступном или заполненном хранилище игра продолжает работать без сохранения.

## Проверка вручную

Откройте страницу по HTTP(S), проверьте три уровня, верные и неверные буквы, выбранную ячейку с подсказкой, обновление страницы посреди партии и повторное открытие страницы после победы/поражения. Проверьте также CSV с запятой, кавычками, CRLF и BOM.
