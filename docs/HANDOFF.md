## Важные находки

- Sumplete: проверяется диагональ, но инструкция её не описывает; генератор не считает число решений, подсказки/ошибки сверяются с единственным скрытым шаблоном. Найдены конкретные поля с двумя решениями; fixture и исходный скрипт сохранены.
- Sumplete сохраняет HTML целиком, использует общий ключ `loadgame` без защиты ошибок storage; размер поля ограничен 360px; новый размер доступен только после конца/показа ответа; регистрация отсутствующего `sw.js`.
- ArcoMage: главная открывает внешний `https://arcomage.github.io/`; локальные `arcomage-hd/` и `dist/` — сборки. В этой папке не найдены `src`, `.ts/.tsx`, `package.json`, lockfile/config исходного проекта. JavaScript для исполнения есть, полного исходного проекта для удобной пересборки не обнаружено. Пользователь мог иметь в виду именно эти JS; исходники также могут быть вне обследованной папки.
- ArcoMage local HTML использует `/assets/...`, `/manifest.webmanifest`, `/registerSW.js`; регистратор берёт `/sw.js` со scope `/`. Для подпапки это неверно. Исправления должны охватывать lazy chunks, CSS/медиа, manifest и SW. Не переписывать minified JS вслепую и не менять ссылку на главной до готовности локального запуска.
- RSVP: оболочка грузит SWF через Ruffle, фиксированный player 800×600 с max-width, метаданные SWF в исследовании 600×500. Полная игровая приёмка не выполнена.
- В тестовом headless WebKit у внешнего ArcoMage встречалась ошибка AudioContext. Это не доказательство ошибки на реальном iPad. Black/loading/play screens Ruffle также не доказывают неработоспособность или успешную игровую сессию.
