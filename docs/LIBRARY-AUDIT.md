# Обзор Игротеки — 16.10.2026

Обследованы исходные локальные страницы и публичные адреса в изолированных Chromium/WebKit на размерах 1024×768 и 412×915. Полные игровые сессии Flash и физические iPad/Android не проходили. Результаты конкретного запуска, а не постоянная гарантия сайта. Код игр при обзоре не меняли.

## Sumplete: подтверждённые факты

`sumplete/index.html` объединяет генерацию, UI и storage. Генератор создаёт случайный набор выбранных клеток `.solution`, рассчитывает по нему цели и скрывает этот выбор. Подсчёта числа решений нет. Победа проверяет суммы строк, столбцов И главной диагонали; инструкция говорит только о первых двух. «Ошибки» и «Подсказка» используют `.solution`, а не поиск совместимого решения.

Исследовательский перебор нашёл минимум два разных допустимых ответа на конкретных полях:

| Размер | Случайная выборка | Найдено полей с ≥2 решениями |
|---|---:|---:|
| 3×3 | 300 | 0 |
| 4×4 | 200 | 0 |
| 5×5 | 200 | 2 |
| 7×7 | 50 | 2 |

Для 3×3 перебраны все 512 масок. Для остальных перебирались допустимые маски строк с проверкой столбцов/диагонали, остановкой после второго решения и лимитом посещённых узлов. Нулевой результат не доказывает единственность всех полей; проценты не являются статистической оценкой вероятности ошибки. Начальные зелёные клетки в текущем UI изменяемы; найденные решения проверены по реально применяемым суммам, без нового предположения, что эти клетки заблокированы.

**Вывод из кода и найденных примеров:** подсказки/ошибки могут противоречить другому допустимому решению, тогда как проверка победы примет любой набор с нужными суммами. Это приоритетнее оформления.

Tracked fixtures: `tests/fixtures/sumplete-ambiguous.json`. В `rowMasks` младший бит означает левую клетку строки, бит 1 — оставить число; оба решения удовлетворяют всем перечисленным целям. Использовать их для будущих регрессий и обсуждения роли начальных clues. Они не доказывают корректность будущего solver без независимых тестов.

Другие факты по коду:

- `localStorage.loadgame` хранит HTML игровой области, ошибки чтения/записи не защищены. Существующую партию надо мигрировать, а не считать сохранений нет.
- Поле `max-width:360px`; крупные размеры дают маленькие клетки даже на планшете.
- Выбор размера и новая партия находятся внутри блока, скрытого до конца/показа ответа.
- Состояние клетки циклически меняется при нажатии: неопределённая → удалить → оставить → неопределённая. Undo отсутствует.
- Есть запрет zoom в viewport и dblclick; есть попытка регистрации `sumplete/sw.js`, которого нет локально и который вернул 404 в WebKit-проверке.

## RSVP

Оболочка загружает `rsvp.swf` локальным Ruffle. Player имеет width 800px, height 600px, max-width 100vw. На телефоне наблюдался контейнер 412×600; высота не подстраивается к ширине/метаданным и доступной высоте. Метаданные SWF в тесте: 600×500, 30 fps. Не выводить размеры контента из размеров контейнера.

Нет меню возврата, русской памятки, собственного error/retry UI. Изменения правил/текста внутри Flash требуют отдельного анализа SWF; это нельзя обещать как CSS-правку. Shared Ruffle используется также Jelly Battle, которая теперь исключена: runtime не менять.

Загрузка metadata/кнопка Play/флаг isPlaying не доказывают полноценную игру. В headless снимках были стартовые/чёрные экраны. Требуется отдельная функциональная приёмка на следующем этапе; это не диагноз «игра сломана на планшете».

## ArcoMage

На главной ссылка на внешний `https://arcomage.github.io/` с target blank. Папка `arcomage-hd/` не используется этой ссылкой. Найден локальный дистрибутив плюс `dist/`, но не исходный проект с build scripts/config. HTML и registerSW используют root-relative пути. Подробный план: `ARCOMAGE-SELF-HOSTING.md`.

Внешняя игра в Chromium открылась; в portrait показала просьбу повернуть телефон. В тестовом WebKit получена ошибка AudioContext; не переносить вывод на физический Safari без воспроизведения. Возможности языка RU, ИИ и offline заявлены в [официальном README](https://github.com/arcomage/arcomage-hd/blob/main/README.md); их нужно повторно принять уже на собственной сборке.

## Главная

Описание Криптографа говорит о стихотворении, а игра работает с фразами/цитатами. Sumplete описана как «по типу Судоку», что не объясняет суммы. Нет общей навигации из разрешённых внутренних игр. Нужны практические отметки управления и ориентации, проверенные на устройстве. Для карточки Jelly Battle изменений не планировать.

## Где исходные доказательства

В локальном `_work/library-audit/` сохранены scripts, JSON и PNG; их не удалять и не выдавать за tracked CI. Скрипт `solutions.cjs` повторяет случайное исследование, не фиксирует seed. В `tests/fixtures/` вынесены конкретные проверяемые данные. Ранний обзор содержал Jelly Battle, но по более позднему прямому указанию пользователя она полностью исключена из дальнейших работ.
