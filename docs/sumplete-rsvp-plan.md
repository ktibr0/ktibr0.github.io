## Контракт Sumplete

Суммы строк, столбцов и главной диагонали обязательны. Неопределённые клетки учитываются в текущей сумме, как раньше. Стартовые зелёные клетки остаются изменяемыми отметками, не дополнительными условиями solver. Победа определяется суммами, а не скрытым шаблоном; все допустимые решения старого поля принимаются.

Чистое ядро UMD/CommonJS `SumpleteGame`: puzzle `{size,numbers:number[][],rowTargets,columnTargets,diagonalTarget,initial:number[]}`; состояния плоские `0` неизвестно, `1` оставить, `-1` убрать. `targets(numbers, kept)` возвращает три вида сумм; `isSolved(puzzle, states)` учитывает все не удалённые клетки; `solve(puzzle,{states?,maxNodes?,deadline?})` возвращает `{count,solutions,exhausted,nodes}` (solutions — плоские 1/-1, count не больше 2, exhausted=true означает незавершённый поиск). Нельзя считать count=1 доказанной единственностью при exhausted=true. Поиск не мутирует аргументы. Невалидные данные отклоняются.

`mistakes(puzzle,states)` возвращает индексы явных отметок, которые невозможны ни в одном решении; при совместном конфликте отдельно допустимых отметок UI объясняет конфликт, не обвиняет произвольную клетку. `hint(puzzle,states)` возвращает `{index,state}` только если ход совместим с текущими отметками и доказан во всех совместимых решениях; иначе null. Подсказки не обязаны удалять только числа. Подсказка не блокирует редактирование и отмену.

`SumpleteGenerator.generate(size,options)` возвращает puzzle; каждая выдача должна иметь доказанное одно решение. Ограниченные попытки/узлы/время; при исчерпании использовать конструктивно единственный простой запасной вариант, никогда непроверенное случайное поле. Размеры 3…9. Сложность размером не объявлять; логические объяснения реализовать после исправления solver (дополнение ниже).

Сохранение `sumplete.save.v1`: `{version:1,puzzle,states,history,revealed}`. History — снимки states для undo, максимум 100. Валидация значений/размеров/сумм и истории. HTML старого `loadgame` разбирать только инертным DOMParser, не вставлять в документ; переносить числа, суммы, отметки и revealed. Старый ключ удалять лишь после успешной записи нового. Нельзя удалять неизвестный/повреждённый legacy; при ошибке дать понятное сообщение и рабочую новую игру. Storage denied/quota не мешает игре.

Интерфейс: `#grid`, `.number[data-index]`, `.hanswer`, `.vanswer`, `.canswer`; кнопки `#mistakes`, `#hint`, `#undo`, `#restart`, `#reveal`, `#new`, `#size`, режимы `#mode-cycle`, `#mode-keep`, `#mode-remove`, `#mode-clear`; статусы `#status`, `#storage-status`. Цикл неизвестно→убрать→оставить→неизвестно; явные режимы + возможность снять отметку. `window.sumplete.getState()` возвращает копию сохранения. Размер и новая партия доступны всегда, подтверждение при незавершённом прогрессе. Reload и undo сохраняют партию. Поле минимум 44px на клетку с внутренней прокруткой для 9×9 на телефоне. Таблетное поле больше прежних 360px. Zoom разрешён, focus, reduced motion, safe area. Отсутствующий SW не регистрировать.

## Контракт RSVP

Русская оболочка, возврат `../`, памятка, старт после касания `#start`, повтор `#retry`, звук `#sound`, fullscreen `#fullscreen`, `#status`, контейнер `#player`. Метаданные прежнего SWF 600×500 служат начальным aspect ratio; после загрузки использовать metadata. Вписывать в ширину и доступную высоту, включая низкий landscape. Отлавливать отказ загрузки/runtime, таймаут, повтор, отказ fullscreen; aria-live и доступные кнопки. Памятка не должна обещать непроверенное управление. Не обещать сохранение позиции или перевод SWF. Реальный сценарий start→меню→игровое действие с изменением поля фиксировать screenshots; отдельно ошибки/повтор, mute, fullscreen fallback, поворот, оба движка.

## Независимые проверки

Основной агент пишет тесты до реализации: неоднозначные fixtures и оба решения; solver против полного перебора малых полей; диагональ, нулевые суммы, все/ничего, бюджет; выдача генератора для всех размеров и forced fallback. Browser: реальные нажатия, неверный/верный ход, hint, undo, победа, reload, безопасная legacy миграция, corrupt/denied/quota, отмена новой партии, быстрые касания. Chromium/WebKit × 1024×768, 1180×820, 412×915, 360×800, 1024×600; визуальное ревью screenshots и регрессия Криптографа. Физические iPad/Android не считать проверенными headless браузером.

## Оценка логики и объяснение подсказок

`SumpleteGame.analyzeLogic(puzzle,states?)` последовательно перебирает допустимые подмножества каждой строки, столбца и диагонали, применяя общие всем подмножествам решения до остановки. Возвращает `{solved,contradiction,states,steps}`; шаг `{index,state,kind,line,target}`, kind=`row|column|diagonal`, line — индекс с нуля. Число проходов ограничено числом клеток+1. Это описание требуемого приёма, не обещание объективной человеческой сложности. Из пустых отметок UI `#logic-level` пишет «Прямые выводы по суммам» при решении этими приёмами, иначе «Совместный анализ нескольких сумм». Размер не является уровнем. При ошибочных данных или превышении бюджета честная нейтральная подпись.

`hint` сначала проверяет совместимость текущих отметок solver; затем предпочитает первый логический шаг с `reason` вида «Строка 2: среди всех вариантов с суммой 12 это число всегда нужно оставить». Если локальных выводов нет, остаётся проверенный глобальный ход и объяснение совместного анализа. Нельзя подсказывать из противоречивой позиции. Изменения ограничить `game.js`, `app.js`, `index.html`; предыдущую семантику undo/save не менять. Независимые тесты проверяют каждый шаг против полного перебора, результат и немутируемость, а не конкретный порядок вывода.
