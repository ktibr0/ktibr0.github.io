# Приёмка PaperGames

Независимые сценарии написаны основным агентом до завершения реализации. Запуск выполняет отдельная Luna 6 low. Исполнитель не меняет проверки ради PASS; ошибки передаются основному агенту.

```text
node tests/papergames/static.cjs
node tests/papergames/acceptance.cjs
node tests/papergames/published.cjs
node tests/cryptographer/rules.cjs
node tests/cryptographer/acceptance.cjs
```

Требуются Node и Playwright с Chromium/WebKit. В окружении можно указать `PLAYWRIGHT_MODULE_ROOT` (каталог node_modules), `PLAYWRIGHT_CHROMIUM_EXECUTABLE`, `PLAYWRIGHT_WEBKIT_EXECUTABLE`. Игрокам эти зависимости не нужны.

Результаты и screenshots сохраняются в `_work/papergames/local/`. Основной агент отдельно просматривает изображения. Скрипт поднимает свой временный сервер с правильными MIME и намеренным 503 для проверки сбоя установки; посторонняя service-worker регистрация и кеш существуют только в одноразовом браузерном профиле.

`PAPERGAMES_RUN_ID` добавляет подкаталог прогона, сохраняя предыдущие материалы. `PAPERGAMES_BASE_COMMIT` задаёт опубликованную базу проверки неизменности старых игр при интеграции параллельного выпуска (по умолчанию `9c41355`, уже опубликованные Sumplete/RSVP). Ожидания игровой логики и точные исходные хеши от этого не меняются.

У используемого WebKit 2359 воспроизводится [ошибка Playwright 42775](https://github.com/microsoft/playwright/issues/42775): `setOffline(true)` запрещает даже ответ Service Worker без обращения к сети. Поэтому локальный сценарий WebKit останавливает сам HTTP-сервер, проверяет отказ несохранённого маршрута и затем требует `response.fromServiceWorker()` для всех семи игр. Это проверка недоступного origin, не заявление об эквивалентности отключению связи на iPad. Chromium проверяется через `setOffline(true)`. В публичном прогоне WebKit этот отдельный сценарий явно отмечается skipped: внешний сервер останавливать нельзя, локальная проверка недоступности origin сохраняется.

После публикации повторный запуск с `PAPERGAMES_BASE_URL=https://ktibr0.github.io` сохраняет результаты в `_work/papergames/live/`. Внешний сервер не предоставляет тестовых маршрутов: проверки искусственного сбоя и посторонней регистрации выполняются только локально. Остальные сценарии, включая настоящий офлайн, выполняются и публично.

Пределы: это проверка интеграции оригинальных движков, а не доказательство корректности всех генерируемых головоломок. Хеши исходных игровых ядер и наборов задач фиксируются независимо от manifest реализации. Headless WebKit не заменяет приёмку на физическом iPad.

`published.cjs` запускается после deploy и проверяет весь публичный пакет (71 файл: HTTP 200 и совпадение SHA-256; CRLF/LF нормализуются для текстов). `PAPERGAMES_RELEASE_SHA` добавляется к URL как cache-busting; результаты — `_work/papergames/published-files.json`.
